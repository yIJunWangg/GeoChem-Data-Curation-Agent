# 项目优化计划

## 任务 1：设置页面 API Key 直接输入

### 后端

**文件**: `src/geochem/web/api.py`

修改 `PUT /api/v1/settings` 端点，支持保存 API Key：
```python
class SettingsUpdateRequest(BaseModel):
    default_provider: str
    default_model: str
    vision_provider: str = ""
    vision_model: str = ""
    api_keys: dict[str, str] = {}  # {provider_name: api_key}
```

保存逻辑：
- `api_keys` 中的 Key 写入 `config/settings.yaml` 对应 provider 的 `api_key` 字段
- 如果 Key 以 `sk-` 开头，直接保存
- 如果用户输入空字符串，清除该 provider 的 Key

**文件**: `src/geochem/core/config.py`

`save_config()` 已支持保存 providers，确认 api_key 字段可写入。

## 任务 3：统一 API 错误处理

**文件**: `src/geochem/web/api.py`

添加全局异常处理中间件：
```python
from fastapi import Request
from fastapi.responses import JSONResponse

@app.exception_handler(Exception)
async def global_exception_handler(request: Request, exc: Exception):
    return JSONResponse(status_code=500, content={"error": str(exc)})
```

对需要特殊处理的 ValueError：
```python
@app.exception_handler(ValueError)
async def value_error_handler(request: Request, exc: ValueError):
    return JSONResponse(status_code=400, content={"error": str(exc)})
```
