# 项目存储目录修改

## 问题
默认项目目录在 `~/GeoChem_Projects/`，用户希望改为项目根目录下的子文件夹。

## 修改

**文件**: `src/geochem/core/config.py`

```python
# 改前
DEFAULT_PROJECT_DIR = Path.home() / "GeoChem_Projects"

# 改后
DEFAULT_PROJECT_DIR = Path(__file__).resolve().parents[3] / "geochem-projects"
```

这会把数据存到 `<项目根>/geochem-projects/` 下。

同时更新 `config/settings.yaml` 中的 `default_project_dir`。

## 验证
1. 启动后确认新项目创建在 `<项目根>/geochem-projects/` 下
2. 导入 PDF 后确认文件在新目录中
